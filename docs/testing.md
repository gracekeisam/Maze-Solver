# Testing

## Ultrasonic Sensor Test

The robot was tested by placing obstacles at different distances
and observing the readings through the Serial Monitor.

## Motor Test

Both motors were tested for:

- Forward movement
- Reverse movement
- Left rotation
- Right rotation
- Stopping

## Maze Test

The robot was tested in a maze environment to verify:

- Front obstacle detection
- Left/right path selection
- Turning
- Reverse movement
- Continuous navigation
